# 🇹🇼 台灣足跡地圖 (Taiwan Footprint Map)

這是一款純前端（Pure Front-end）開發的台灣旅行足跡記錄系統。使用者可以在互動式地圖上標記旅遊照片，並透過內建的動態回顧與猜謎小遊戲重溫美好回憶。系統採用「本地優先（Local-First）」架構，所有照片與地理資料皆安全地儲存於使用者設備的瀏覽器中，無須後端伺服器，確保 100% 的絕對隱私。

## 🛠 技術堆疊 (Tech Stack)
* **前端介面**：HTML5, CSS3, Vanilla JavaScript (ES6+)
* **地圖引擎**：[Leaflet.js](https://leafletjs.com/) 搭配 TopoJSON 離線向量邊界
* **本地資料庫**：IndexedDB (支援非同步大容量儲存 Blobs)
* **效能優化**：Canvas 階梯式影像壓縮、128KB 局部 EXIF 讀取、Object URL 動態記憶體回收

## ⚙️ 功能與記憶體 (RAM / ROM) 運作機制

### 一、 地圖瀏覽與照片管理
| 功能名稱與完整操作步驟 | RAM (暫存記憶體) 使用動作 | ROM (本地儲存 IndexedDB) 使用動作 |
| :--- | :--- | :--- |
| **地圖瀏覽與動態生物**<br>1. 拖曳、縮放 Leaflet 地圖<br>2. 觀看海洋生物與海浪動畫 | 載入 TopoJSON 幾何陣列判定陸地；維持地標叢集 (MarkerCluster) 與 SVG 元件；定時器計算生物碰撞。 | 讀取 LocalStorage 偏好設定與 IndexedDB 內的 `photoMeta` 產生圖釘座標。 |
| **批次上傳與防 OOM 處理**<br>1. 點選多張圖檔<br>2. 填寫預設地區/年份並匯入 | 切取前 128KB 檔案片段解析 EXIF；宣告 Canvas 降階壓縮；生成 Blob 與短暫的 Object URL 後立刻強制回收。 | 將壓縮後縮圖與展示大圖寫入 `photoBlobs` 表；將經緯度與標籤寫入 `photoMeta` 表。 |
| **單張照片檢視與編輯**<br>1. 點擊地圖圖釘展開縮圖氣泡<br>2. 開啟全螢幕燈箱<br>3. 編輯或刪除 | 氣泡展開時動態將縮圖轉為 Object URL；開啟大圖時載入高畫質 Blob URL；關閉時立即釋放 RAM 資源。 | 依 ID 讀取圖檔；儲存時更新 `photoMeta`；刪除時從雙表移除紀錄並真實釋放硬碟。 |
| **批次刪除照片**<br>1. 進入「批次刪除」<br>2. 篩選年份/月份/地區並勾選<br>3. 確認刪除 | 篩選時將符合條件的縮圖轉換為 URL 顯示於清單；關閉視窗或刪除後強制全數回收以釋放記憶體。 | 執行刪除時遍歷 Set 集合，從 IndexedDB 同步移除大量紀錄，真實釋放硬碟空間。 |

### 二、 動態展示與回顧
| 功能名稱與完整操作步驟 | RAM (暫存記憶體) 使用動作 | ROM (本地儲存 IndexedDB) 使用動作 |
| :--- | :--- | :--- |
| **幻燈片輪播**<br>1. 進入「幻燈片輪播」<br>2. 設定篩選條件並開始 | 每次切換幻燈片時，將當前照片轉為 Object URL 載入；切換下一張時主動撤銷前一張的 URL 避免溢位。 | 依據排序陣列，定時從 `photoBlobs` 撈取單張大圖片資料 (`displayBlob`)。 |
| **行動態回顧**<br>1. 進入「行動態回顧」篩選排版<br>2. 設定字卡與自訂箭頭<br>3. 點擊開始，地圖依序飛行 | 繪製軌跡折線 (含抗縮放效果) 與標記的逐幀動畫；預載展示站點大圖與縮圖 URL；動畫結束後全數清空。 | 播放期間密集讀取目標照片 `thumbBlob` 與 `displayBlob` 渲染彈出氣泡；讀取自訂箭頭。 |

### 三、 小遊戲與系統管理
| 功能名稱與完整操作步驟 | RAM (暫存記憶體) 使用動作 | ROM (本地儲存 IndexedDB) 使用動作 |
| :--- | :--- | :--- |
| **猜謎小遊戲 (休閒/挑戰)**<br>1. 進入「猜謎小遊戲」<br>2. 篩選題庫並設定題數<br>3. 選擇 9 種特效模式並答題 | 載入單張大圖 URL；依據模式進行高強度 Canvas 像素運算（如 8-Bit 動態馬賽克、邊緣偵測）；建立離線畫布。 | 讀取題庫對應的 `photoMeta` 生成正確與干擾選項；讀取大圖生成遊戲畫面。 |
| **自訂小遊戲精靈**<br>1. 進入「自訂小遊戲」點擊建立<br>2. 勾選題庫並編輯選項<br>3. 點擊儲存 | 在編輯清單中批次載入所有勾選照片的縮圖 URL；切換步驟時動態生成表單；關閉精靈時釋放陣列。 | 將自訂的題目敘述、選項陣列、綁定特效與基本設定寫入專屬的 `customGames` 資料表。 |
| **系統備份與還原**<br>1. 進入「系統設定」<br>2. 點擊「匯出/匯入」資料 | 匯出時，逐筆將圖檔 Blob 轉為 Base64 字串，拼接成 JSON Blob 觸發下載；匯入時將 JSON 讀入記憶體解析。 | 匯出時讀取全庫資料；匯入時執行大規模覆寫，同步更新手機/電腦硬碟中的 IndexedDB。 |

## 🚀 部署與發佈指南 (GitHub Pages 免費上線)

本專案無須後端伺服器，可直接透過 GitHub Pages 免費發佈上線。

1. **建立 Repository**：在 GitHub 新增一個 Public Repository。
2. **上傳核心檔案**：將以下 10 個核心檔案拖曳至 Repository 內並 `Commit`：
   * `index.html`
   * `style.css`
   * `app-core.js`
   * `app.js`
   * `game.js`
   * `taiwan-country.topo.json`
   * SVG 素材：`whale.svg`, `dolphins.svg`, `diver.svg`, `turtle.svg`
   *(⚠️ 請勿上傳包含個人照片的備份 JSON 檔)*
3. **開啟 GitHub Pages**：
   * 進入專案的 `Settings` > `Pages`。
   * 在 Source 選擇 `Deploy from a branch`，Branch 選擇 `main` 並儲存。
   * **強烈建議勾選 `Enforce HTTPS`**，以確保定位與本地資料庫的高階權限可正常運作。
4. **取得專屬網址**：等待約 1~2 分鐘後，即可取得類似 `https://<你的帳號>.github.io/<專案名稱>/` 的網址，點擊即可使用！

本系統的所有照片檔案、地理座標與備份資料，皆採用瀏覽器本地儲存（IndexedDB）技術。資料 **絕對不會** 傳輸至 GitHub 或任何外部伺服器。若需跨裝置使用（例如從電腦轉移至手機），請使用系統內建的「匯出 / 匯入」功能手動轉移 JSON 檔案。
